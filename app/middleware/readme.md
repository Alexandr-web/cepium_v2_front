# Middleware в Nuxt 4

Папка `app/middleware/` содержит навигационные стражники (middleware), которые выполняются перед переходом на определённую страницу или группой страниц. Они позволяют контролировать доступ, перенаправлять пользователей, проверять аутентификацию и т.д.

## Основные концепции

- **Именованный middleware** – применяется к конкретным страницам через мета-поля в `router.options.ts`.
- **Глобальный middleware** – выполняется при каждом изменении маршрута (префикс `.global.` в имени файла).

## Middleware в проекте

| Файл | Тип | Назначение |
|------|-----|-----------|
| `auth.ts` | Именованный | Проверка авторизации. Перенаправляет на `/login`, если пользователь не авторизован. Применяется к защищённым маршрутам (`home`, `configs`, `profile`, `statistics`, `orders`). |
| `login.ts` | Именованный | Защита страницы входа. Перенаправляет на `/`, если пользователь уже авторизован. |
| `socket.global.ts` | Глобальный | Управление WebSocket-подключением. Пропускает страницы с мета-полем `noSocket` (например, `/login`). |

## Создание middleware

Файл в `middleware/` должен экспортировать функцию (или объект с `default`).

### Пример: `auth.ts`

```ts
export default defineNuxtRouteMiddleware((to, from) => {
  const user = useUserStore();
  if (!user.isLoggedIn) {
    return navigateTo('/login');
  }
});
```
